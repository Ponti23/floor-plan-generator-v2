## Defects found and fixed

1. **Pointer/zoom anchor drift.** `src/app/main.ts` kept a second hand-written
   root viewBox margin, while `src/app/svg-projection.ts` rendered a different root.
   Fixed with one exported `planViewBox()` used by both rendering and viewport maths;
   added regression test.
2. **Toolbar/viewport glyph fallback.** Unicode symbols rendered as `-`/blank in
   headless Chrome. Replaced with inline SVG icons in `main.ts`.
3. **Option-card geometry mismatch.** The fidelity pass had removed
   `grid-template-columns`, making the score fall to a second row and growing cards
   to 246 px versus the reference's ~191 px. Restored a three-column top row and
   pinned card height to 191 px with a 142 px thumbnail band.
4. **Expand-room button accessible name.** The `⌃`/`⌄` button had no useful name.
   Added `aria-label` with the room name.
5. **Viewport tool toggle state.** Select/pan buttons used only `.active` and
   lacked `aria-pressed`. Added pressed state.
6. **Landmark/semantic roles.** Viewport tools, legend, and north indicator had
   `aria-label` without roles. Added `role="group"` and `role="img"` respectively.
7. **Locale-sensitive display formatting.** `analysis-projection.ts` used
   `toLocaleString`, which can change decimal separators across browsers/locales.
   Switched to deterministic `toFixed`.
