## D1 — Shell: retain Vite + TypeScript (recommended)

**APPROVED 2026-09-15** (user: "as long as we can deploy to vercel easily"). Deployment fact checked
in the same session: `npm run build` emits a static `dist/` (index.html + hashed JS/CSS plus a
separate worker chunk, 438 ms), which Vercel serves with its auto-detected Vite preset — build
command `npm run build`, output directory `dist`, no `vercel.json` required and no server runtime.

Evidence: `package.json`, `vite.config.*`, `src/app/main.ts`, `src/worker/`.

- This MVP is a single-page, client-side generator with a Web Worker. There is no backend, no SSR,
  no routing, no server actions, no auth, and no data layer.
- Next.js would add a server runtime and framework surface that currently has no consumer, and would
  risk the verified worker protocol and build gates.

**Decision requested:** keep Vite + TypeScript, or direct a migration to Next.js.
